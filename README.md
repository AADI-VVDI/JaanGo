# About Project
This project builds a machine learning–based traffic violation detection system that monitors a zebra crossing and stop line using YOLOv8 and OpenCV. It detects pedestrians and vehicles in real time and identifies violations when a vehicle crosses the stop line while a pedestrian is on the zebra crossing. When a violation occurs, the system captures the vehicle image and sends it to authorities through a Flask-based web dashboard.

Additional features include a pedestrian-responsive smart traffic signal, a sound alert system, and zone-based safety detection (safe/danger zones).
